# Results

This directory is reserved for generated evaluation outputs.

The repository does not commit fabricated metrics. Run the pipeline on the actual dataset to generate trustworthy results.

For the assignment report, record:

- supervised PR-AUC
- Isolation Forest PR-AUC
- precision
- recall
- F1
- selected threshold
- false positives
- false negatives
- drift PSI statistics
- whether the retraining alert fired
